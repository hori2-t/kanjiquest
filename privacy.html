プライバシーポリシー

最終更新日: 2026年10月21日

hori2（以下「開発者」）は、本アプリ「カンジクエスト (KanjiQuest)」（以下「本アプリ」）における利用者およびその保護者の方々のプライバシー保護を最重要事項と考えています。本ポリシーは、本アプリが取り扱う情報の種類・目的・保護方針を明確にするものです。

本アプリについて
本アプリは漢字検定 3 級〜10 級に対応した学習アプリで、幅広い年齢層が利用できる学習アプリです。年齢区分を回答しなくても学習できます。未成年の利用については保護者の方も本ポリシーをご確認ください。
適用するバージョン
年齢区分と追跡許可に応じた広告利用、および広告なし追加回復の説明はバージョン1.1.3以降に適用します。公開中の1.1.2にはこの年齢・許可の分岐がありません。1.1.2では年齢回答やATT許可を開始条件にせず、Googleの同意管理で広告要求が許可された場合に広告SDKを開始します。広告のパーソナライズを無効にする設定はありますが、1.1.3で追加したSDK側のパブリッシャーのファーストパーティID無効化と、広告要求ごとの非パーソナライズ指定はありません。GoogleのSDKによる識別子・概算位置・広告操作・診断等の取扱いは、旧版についてもなくなるものではありません。1.1.3の動作説明を旧版へ遡って適用しません。以前Googleへ送信された情報は、アプリの更新や終了で取り消されるものではありません。

1. 収集する情報

本アプリの学習機能は、学習データを端末内で処理・保存します。広告と同意管理には Google の SDK を使用し、これらの SDK が取り扱う情報は以下および第 7 項のとおりです。

位置情報位置情報 API は使用しませんGoogle の SDK は IP アドレスから概算の位置情報を推定・処理する場合があります。精密な位置情報を要求する機能はありません。

2. 端末内に保存されるデータ

本アプリは、利用者の学習体験向上のため、以下のデータを端末内のみに保存します。これらのデータは外部サーバーへ送信されることはありません。

  • 学習履歴（出題された漢字、正誤、回答時間、復習スケジュール）
  • 進捗データ（XP、レベル、ストリーク、達成バッジ）
  • 漢字図鑑のコレクション情報、相棒の選択・育成・進化の進捗
  • アプリ設定（通知時刻、表示設定、難易度、目標セッション数など）
  • 1.1.3以降の年齢区分（未回答・18歳未満・18歳以上）。生年月日や身分証は取得しません。

これらのデータは iOS の標準保存領域（SwiftData / 端末内 SQLite および UserDefaults）に保存されます。本アプリの削除によって端末内のアプリ保存領域は削除されます。OSのバックアップやGoogle側が扱った情報まで削除する操作ではありません。年齢区分は設定で変更できます。学習データのリセットと年齢区分の変更は別の操作です。

3. Sign in with Apple について

現行バージョンでは Sign in with Apple を提供していません。将来、サインインやデータ同期を提供する場合は、提供前に本ポリシーを更新します。

4. 手書き認識について

本アプリの書きクエストでは、Apple Pencil または指で漢字を書いて回答できます。手書きデータの認識処理には Apple の PencilKit と Vision フレームワーク（端末内 OCR）を使用し、すべての処理は端末内で完結します。手書きデータはサーバーへ送信されることはなく、解答と確認のため端末内で扱います。

5. 通知について

本アプリは、利用者が通知機能を ON にした場合に限り、以下のローカル通知を送信します。通知はすべて端末内で完結し、外部サーバーを経由しません。

  • デイリーリマインダー（学習の習慣化サポート）
  • ラストコール通知（ストリーク維持のためのリマインド）
  • 昼休み通知（任意の時間帯設定）

利用者はいつでもアプリ設定または iOS の設定アプリから ON/OFF を切り替えられます。

6. アプリ内課金（IAP）について

バージョン1.1.3は無料で、漢検 10 級〜3 級の学習機能を提供しています。アプリ内課金、コース購入および「購入を復元」の操作は提供していません。本アプリが Apple ID やクレジットカード情報を取得することはありません。Appleから確認したアプリ取得情報や過去の購入権利の確認結果を端末内に保存する場合があります。これらの確認で新たな購入は行わず、1.1.3の全対象級の無料利用は変わりません。

7. 広告と同意管理について

1.1.3では、18歳以上と回答しiOSの追跡を許可した利用者が、必要なGoogleの同意手続きを経て、任意でGoogle AdMobのリワード広告を利用できます。年齢未回答・18歳未満では、追跡許可を求めず、本アプリから広告SDKやGoogle User Messaging Platform（UMP）を開始しません。成人でも追跡許可が未選択・拒否・利用制限の場合は開始・同意更新・広告要求を行いません。

追跡許可は設定の「広告の追跡許可」から任意で選択します。追跡許可にハートやXPの報酬を付けません。成人は許可状態にかかわらず広告なしでハートを回復する経路を利用でき、許可した場合も選べます。追加回復はハート0のとき1個、広告の有無を合わせて最大3回/日です。学習、自然回復、既存の1日無料回復は利用できます。許可変更で回復上限は増えません。

広告を利用できる場合でも、パーソナライズ無効・publisher first-party ID無効・非パーソナライズ広告の要求設定は維持します。これらの設定をすべての識別子やデータ処理がなくなる保証とは説明しません。成人の広告では児童向け扱いを指定せず、一般向けの広告レーティングを使用します。

広告会社が広告表示や効果測定に他社アプリ・ウェブサイト等の情報との関連付けを用いる可能性があるため、本アプリではiOSの追跡許可を広告SDKの開始条件にします。GoogleのSDKは、IPアドレス由来の概算位置、端末またはアプリに関連する識別子、広告データ・操作、診断情報を広告配信・解析・品質改善に処理する場合があります。UMPは同意管理に必要な情報を処理する場合があります。氏名・アカウントがなくても端末への関連付けがないとは限りません。

年齢や許可を変更した場合、本アプリは準備済み広告を使わず、追加要求・表示・再読み込みを防ぎます。一度開始したSDKには本アプリから完全終了するAPIがないため、許可撤回を観測した場合は、その起動中に再許可しても広告を再開しません。開始済みSDKを終了するにはアプリを終了して再起動する必要があります。学習と広告なしの回復は引き続き利用できます。変更前に送信した要求やGoogle側の保持情報まで取り消す・削除する保証はありません。

Google側の取扱い、保存・削除やプライバシー選択はGoogleプライバシーポリシーとGoogleのサービスを使用するサイトやアプリから収集した情報の使用をご確認ください。端末内データのリセットやアプリ終了でGoogle側の情報は削除されません。

8. 利用者と保護者の皆さまへ

学習機能にアカウント登録や年齢回答は不要です。氏名・メールアドレス・電話番号を入力する機能や、SNS連携・チャット・利用者間通信は提供していません。本アプリの学習進捗や手書き回答を開発者のサーバーへ送信しません。

1.1.3で未回答または18歳未満の場合、本アプリから広告・同意管理を開始しない運用を行います。18歳以上という区分は本アプリの広告運用方針です。旧版や変更前に送信された情報の取扱いは第7項と適用バージョンの説明をご確認ください。保護者からのご質問は第11項の連絡先へお寄せください。

9. 第三者提供

本アプリは、第 7 項に記載した Google の広告・同意管理 SDK による取扱いを除き、端末内の学習情報を第三者へ提供しません。法令に基づく開示要請がある場合のみ、関連する法令に従って対応します。

10. 本ポリシーの変更

本ポリシーは、法令の改正やサービス内容の変更に応じて改定されることがあります。重要な変更がある場合は、本ページおよびアプリ内で告知します。
