プライバシーポリシー

最終更新日: 2026年5月17日

hori2（以下「開発者」）は、本アプリ「カンジクエスト (KanjiQuest)」（以下「本アプリ」）における利用者およびその保護者の方々のプライバシー保護を最重要事項と考えています。本ポリシーは、本アプリが取り扱う情報の種類・目的・保護方針を明確にするものです。

本アプリについて
本アプリは漢字検定 3 級〜10 級に対応した学習アプリで、児童（小学生〜中学生）の利用を想定して設計されています。本ポリシーは、児童のプライバシー保護に関する国内外の法令（個人情報保護法、米国 COPPA、EU GDPR 等）の精神を尊重して策定しています。

1. 収集する情報

本アプリは、以下のいずれの個人情報も収集しません。

情報の種類収集備考
氏名・メールアドレス・電話番号収集しないアカウント機能なし
位置情報収集しない位置情報 API を使用していません
連絡先・写真・カレンダー収集しない該当 API を使用していません
マイク・カメラ収集しない該当 API を使用していません
健康データ（HealthKit）収集しないHealthKit 非使用
クラッシュレポート・解析データ収集しない非収集
手書きデータ収集しない端末内 OCR で処理後すぐ破棄

2. 端末内に保存されるデータ

本アプリは、利用者の学習体験向上のため、以下のデータを端末内のみに保存します。これらのデータは外部サーバーへ送信されることはありません。

  • 学習履歴（出題された漢字、正誤、回答時間、復習スケジュール）
  • 進捗データ（XP、レベル、ストリーク、達成バッジ）
  • 漢字図鑑のコレクション情報
  • 購入履歴（買い切りコースの所有状況）
  • アプリ設定（通知時刻、表示設定、難易度、目標セッション数など）

これらのデータは iOS の標準保存領域（SwiftData / 端末内 SQLite および UserDefaults）に保存され、本アプリを削除すると同時に完全に消去されます。

3. Sign in with Apple について

本アプリは将来的なデータ同期機能のため、Sign in with Apple をオプションで提供する場合があります。サインインを行った場合でも、Apple から提供されるユーザー識別子は端末内のみに保存され、開発者のサーバーへは送信されません。将来 iCloud 同期を実装する際は、本ポリシーを改定したうえで、明示的にお知らせします。

4. 手書き認識について

本アプリの書きクエストでは、Apple Pencil または指で漢字を書いて回答できます。手書きデータの認識処理には Apple の PencilKit と Vision フレームワーク（端末内 OCR）を使用し、すべての処理は端末内で完結します。手書きデータはサーバーへ送信されることはなく、認識処理後ただちに破棄されます。

5. 通知について

本アプリは、利用者が通知機能を ON にした場合に限り、以下のローカル通知を送信します。通知はすべて端末内で完結し、外部サーバーを経由しません。

  • デイリーリマインダー（学習の習慣化サポート）
  • ラストコール通知（ストリーク維持のためのリマインド）
  • 昼休み通知（任意の時間帯設定）

利用者はいつでもアプリ設定または iOS の設定アプリから ON/OFF を切り替えられます。

6. アプリ内課金（IAP）について

本アプリでは、漢検級別の学習コンテンツを提供する買い切り型のアプリ内課金（7 種類: 8〜3 級コース、およびバンドル）を提供しています。

  • 購入処理はすべて Apple の App Store サーバーを経由して行われ、本アプリがクレジットカード情報等を取得することはありません。
  • 本アプリは購入状況の確認のため Apple が提供する StoreKit 2 の Transaction.currentEntitlements API のみを参照します。
  • 過去の購入を別端末で復元する「購入を復元」機能を提供します。

7. 広告について

本アプリは無料版において、Google AdMob による広告を表示する場合があります。本アプリは児童向けアプリのため、以下の方針で広告を運用します。

  • child-directed treatment (TFCD) フラグを ON に設定し、児童向けに適切な広告のみを配信します。
  • SKAdNetwork ベースの非個人化広告のみを表示し、利用者の行動を追跡するパーソナライズ広告は配信しません。
  • 広告識別子（IDFA）の取得や App Tracking Transparency（ATT）の許可要求は行いません。
  • 有料コース購入後は広告が非表示になる場合があります。

8. 子供のプライバシー（COPPA / 個人情報保護法児童条項）

本アプリは児童の利用を想定しているため、以下の特別な配慮を行っています。

  • 13 歳未満の利用者からも、上記第 1 項に記載のとおり個人情報を一切収集しません。
  • 外部サービスへのデータ送信は、上記第 7 項の TFCD 準拠広告を除いて一切行いません。
  • ソーシャル機能（SNS 連携、チャット、ユーザー間通信等）は一切実装していません。
  • 外部リンク（本ポリシーや利用規約の連絡先メール等）は最小限とし、利用に保護者の判断が必要なものに限定します。

保護者の方からのご要望（アプリの利用状況の確認、データに関するお問い合わせ等）は、第 11 項の連絡先までお寄せください。

9. 第三者提供

本アプリは、第 7 項に記載した TFCD 準拠の広告配信を除き、利用者の情報を第三者へ提供することはありません。法令に基づく開示要請がある場合のみ、関連する法令に従って対応します。

10. 本ポリシーの変更

本ポリシーは、法令の改正やサービス内容の変更に応じて改定されることがあります。重要な変更がある場合は、本ページおよびアプリ内で告知します。
